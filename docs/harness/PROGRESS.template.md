# Progress (template)

Copy this layout into docs/PROGRESS.md.

## State
One paragraph: what exists and runs now.

## Next
Numbered, in order. The first line is what a fresh session does.

## How to resume
Which checkout, branch and forwards a session needs.

## Waiting on the human
Only real blockers, each with what exactly is needed.

## Not verified yet
Every claim that has not run on the real system, with the reason.

## Failing tests
Name, command and the first failing line, or "None".

## Spend
OpenRouter usage against the $3 testing cap, with the date it was read.

## Noticed
Anything seen outside the current task (R10).

## Board history
| Date | Task | Story / agents | Green / blocked / red |
|---|---|---|---|
